# V1

This repository hosts **ContextGate** — an open-source LLM router with semantic
caching, async request handling, and provider-aware context reuse.

The project lives in [`contextgate/`](./contextgate). See its
[README](./contextgate/README.md) for setup, architecture, and usage.

> **Run all commands from inside `contextgate/`** (`cd contextgate` first) —
> that's where `docker-compose.yml`, the app, tests, and benchmark live.
